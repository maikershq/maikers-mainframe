# Affiliate Feature Examples

## Overview

The Mainframe protocol supports affiliate revenue sharing for agent creation fees. Affiliates can earn up to 50% of activation fees when users create agents through their referral.

## SDK Integration

For complete affiliate integration examples and code samples, see the official SDK documentation:

📦 **[Mainframe SDK - Affiliate Examples](https://github.com/maikershq/maikers-mainframe-sdk/tree/main/examples)**

## Key Features

- **Revenue Sharing**: Affiliates earn 0-50% of activation fees
- **Flexible Integration**: Optional affiliate parameters in agent creation
- **Transparent Calculation**: On-chain fee distribution logic
- **Partner Discounts**: Combined with collection-based fee reductions

## Fee Structure

| Affiliate Percentage | Basis Points | Affiliate Share | Protocol Share |
|---------------------|---------------|-----------------|----------------|
| 10% | 1000 | 0.005 SOL | 0.045 SOL |
| 25% | 2500 | 0.0125 SOL | 0.0375 SOL |
| 50% (max) | 5000 | 0.025 SOL | 0.025 SOL |

*Based on 0.05 SOL standard activation fee
